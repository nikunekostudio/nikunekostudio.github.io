ONIKU / RHYTHM CHART EDITOR

たんぽぽリズム 譜面作成ツール

曲を聴きながら、PERFECT にしたい瞬間を４レーンに記録します。

楽曲を読み込み中…

再生中にボタンか 1・2・3・4 / D・F・J・K を押すと、その瞬間が記録されます。停止中は選んだ位置に追加できます。

図の中央が現在位置です。音を聞いてから押す遅れは環境や人により異なります。下の補正や数値編集で調整できます。

記録したノーツ 0 個

時刻は曲の先頭からのミリ秒です。時刻とレーンを直接変更でき、「▶」でその位置へ移動します。

保存と受け渡し

「このブラウザに保存」すると、同じ端末・同じブラウザのゲームで次回の演奏から使えます。他の人のゲームには自動公開されません。

公開版に反映したいときは、書き出した JSON ファイルを渡してください。ゲーム内の端末用タイミング補正とは別に管理されます。ゲームで判定補正を使っている場合、PERFECT の中心は「譜面時刻 − 判定補正」になります。
