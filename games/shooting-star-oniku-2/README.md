# シューティングスターおにく２

2026-10-21 試作版。自機はおにく。通常は約4分半で完結、エクストラは3エリア＋ボスを繰り返す縦スクロールシューティングです。ローカルレビュー版。公開用ソース。ローカル試遊では本番ランキングへの書き込みを無効化しています。

## ストーリー

度重なる増税に怒ったおにくはキッシーダに文句を言いに旅立つのだった。

## 起動

このフォルダーでターミナルを開き、Python 3の場合は次を実行します。

```powershell
python -m http.server 4180 --bind 127.0.0.1
```

http://127.0.0.1:4180/ をブラウザーで開きます。`file://` の直接起動はできません。終了は Ctrl+C です。

現在のワークスペースでは、`work/shooter-preview-server.cjs` がサイト全体を4180番で配信します。プレビューは http://127.0.0.1:4180/games/shooting-star-oniku-2/ です。

## 操作

- 矢印キー／WASD：移動。斜め移動の速度は正規化しています。
- マウス／タッチ：画面内でドラッグ。指を置いた場所へ突然ワープせず、ドラッグの移動量で動きます。
- ショット：自動発射。
- Xキー／BOMBボタン：ショップで購入した爆弾を1個消費。敵弾を消し、画面内の敵に35ダメージ。1.8秒の無敵を与えます。未購入なら使用できません。
- P／Esc／Ⅱボタン：一時停止。別タブや別ウィンドウへ移動した場合もプレイを止めます。
- SOUND：初期はOFF。ONにすると添付のBGM・SEを再生します。

## 進行

| 時間 | 内容 |
| --- | --- |
| 0:00〜1:10 | 森。カブ・鳥・クモ、クマの中ボス |
| 1:10〜2:20 | 海岸。ヤドカリ・鳥・おばけ、大型ヤドカリ |
| 2:20〜3:30 | 街。炎・爆弾・パンクのブタ・牛 |
| 3:30〜4:30 | キッシーダとの最終戦 |

途中クリア画面はありません。背景は非シームレス素材を下端から上端へ一度だけパンし、エリア切替時に1秒クロスフェード。街の背景はボス戦で停止します。最終戦のゲージを削り切ると「文句、届けた！」でクリア。4:30までに倒せなければ再挑戦です。

自機はHP3、中心の小さな円が当たり判定。敵・弾も円形判定で、透明な四角全体には当たりません。

## エクストラモード

タイトルの「エクストラモード」からショップを経て出撃します。ステージ3のキッシーダを倒すと、結果画面を挟まずステージ1の森へ戻ります。周回ごとのHP・猫・装備・ボム残数・スコア・獲得金は維持し、残った敵弾・自機弾・敵を消して2.5秒の無敵を与えます。HPや消耗品の無料補充はありません。

敵HP・移動速度・弾速・攻撃頻度は、1周目100％、2周目130％、3周目169％……と周回クリアごとに1.3倍。背景とステージ進行は通常の速さを維持。突進の予告0.9秒とボス段階変化の予告0.85秒も短縮しません。各周で中ボス・最終ボスが再出現し、BGMも森→海岸→街に戻ります。

エクストラには4:30のボス戦タイムアウトを設けず、HPが尽きるまで続きます。表示タイマーは全周の合計、画面下に周回数と敵倍率を表示。通常・エクストラは共通のハイスコアとランキングを使います。旧 `bestExtra` は通常記録と比較して高い方に統合し、X共有文にはモード・周回数を含めます。

## ショップ・保存

出撃前にショップを表示します。初回に100Gを支給し、装備なしでも出撃可能です。支給済みフラグを保存し、再読み込みで二重支給しません。旧セーブにも初回分を一度だけ加算します。

| 商品 | 値段 | 次の1プレイの効果 |
| --- | ---: | --- |
| コーヒー | 100G / 個 | 1個につきガード1回、最大5回。重弾も1ガードで防ぐ |
| しいたけ | 80G / 段階 | 威力＋25%ずつ、最大Lv.5＝225% |
| まぐろ | 120G / 人 | 1個目で猫、2個目でかに。最大2人で近い敵へ自動射撃 |
| メロンパン | 60G / 段階 | 速度＋20%ずつ、最大Lv.5＝200% |
| 爆弾 | 100G / 個 | 最大5個。1回1個を消費し敵弾消去＋画面内35ダメージ＋短い無敵 |

同じ商品を複数購入できます。段階表示・現在の効果・次段階の効果をショップに表示。購入待ちの個数を保存し、旧セーブの購入済みフラグは1個に移行します。購入した装備は出撃時に消費し、強化は次の1プレイ限りです。猫とかには左右へ追従し、無敵。仲間の弾は1発0.8ダメージで、しいたけによる仲間の火力増加はありません。

財布・購入待ち装備・最高スコアは `oniku-shooter-v1` のlocalStorageへ保存します。保存が使えない場合は同じタブのメモリーだけで続行します。お金は敵撃破ごとに加算・保存し、逃げた敵からは獲得しません。同じ敵の報酬を二重に受け取れません。保存情報は外部送信しません。

| 敵 | HP | 主な行動 |
| --- | ---: | --- |
| カブ | 1 | 5体のV字／斜列編隊。移動は遅め、間引いた狙い弾 |
| 鳥 | 0.55 | 高速の5体編隊。中央機が散開弾を撃つ |
| クモ | 4 | 途中で停止して高速狙撃、しばらくすると撤退 |
| ヤドカリ | 10 | 低速・高耐久。広い3方向弾 |
| おばけ | 3 | 大きく漂い、低速の全周弾 |
| 炎 | 2 | 高速ジグザグ移動と速い狙い弾 |
| 爆弾（敵） | 2 | 停止後に点滅し10方向へ自爆。自爆による報酬はなし |
| パンクのブタ | 12 | 左右に動きながら3方向／5方向の扇弾 |
| 牛 | 7 | 予告線を出し、方向を固定して突進。後追いしない |

中ボス・ボスの段階変化時は既存の敵弾を消し、約0.85秒の攻撃予告を設けます。キッシーダのゲージは3分割・段階別の色で表示します。低HPの編隊機は数が増えるため1体2G、それ以外は5〜10G、中ボス30G、最終ボス100Gです。

バランスは `enemies.mjs` の `SPECIES`・移動・攻撃、`model.mjs` の出現間隔・`ITEMS`で調整できます。価格・HP・攻撃密度は試作の仮値です。課金・オンラインアカウントは未実装です。

## 敵弾の危険度

| 見た目 | 性能 |
| --- | --- |
| 水色・丸 | 通常弾。HP−1 |
| オレンジ・矢印 | 秒速160px以上の高速弾。小さめの判定、HP−1 |
| ピンク・大きな菱形＋外周 | 重弾。秒速85〜100pxの低速・低頻度だがHP−2 |

クモや炎が高速弾、ヤドカリ・パンクのブタ・発狂ボスが通常の弾に少数の重弾を混ぜます。シールドはどの弾も1チャージで防ぎ、被弾後無敵は共通。重弾でHPが負数にならないようにしています。

## 記録・ランキング・X共有

端末内ハイスコアは従来どおり自動保存。結果画面から、公開名20字と今回のスコアを明示的に送信します。匿名プレイヤーIDはサイト内の他ゲームと同じ `nikuneko-player-id` を使用。月間・歴代TOP10をゲーム内に、月間TOP3と先月分を `/games/` に掲載するコードを追加しています。

本番の保存先は既存の `nikuneko-monthly-scores-api`（Cloudflare Worker / D1）。2026-10-21に既存のDBバインディングを維持してAPI更新を実施し、このゲームの歴代GETで200を確認済み。ローカル試遊では送信ボタンを無効化します。APIの記録・月跨ぎ集計は一時SQLiteで検証し、本番データへのテスト投稿はしていません。

APIは月ごとの自己ベストのみ更新し、30秒以内の連続更新を抑制。歴代は全月の各プレイヤー最高値を1件だけ掲載します。現状は従来と同じクライアント申告型スコアで、改ざんを完全に防ぐ認証・サーバー側リプレイ検証はありません。

X共有は投稿画面を開くリンクです。今回のスコア、クリア／到達時間、公開ゲームURL、`#シューティングスターおにく2` `#にくねこスタジオ` を含みます。自動投稿はしません。公開前のURLは本番でゲーム公開後に利用可能になります。
