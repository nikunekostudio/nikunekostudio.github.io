## 多言語SEOの現状と残る課題

既存の ?lang=en / ?lang=ja はそのままです。英語選択時のtitle/description/OGP/Twitterのブラウザ内更新を整備し、既存翻訳の一部抜けも補完しました。既存英語表示はhtml lang=en、日本語のみのゲームはlang=jaを維持しています。紹介文の各言語部分にはlang属性があります。

ただし、現在の言語切替はJavaScriptによる部分翻訳です。クイズの設問や一部ゲームの会話などは日本語のままです。サーバーが返すHTMLとJavaScriptを実行しないSNSクローラーのメタ情報は日本語版です。英語メタ情報だけで「完全な英語版のSEOが完成した」とは言えません。日英両方のゲーム紹介はJavaScriptなしでもHTML内に存在します。

同じサーバーHTMLに対して完全な翻訳版であるかのようなhreflangを付ける既存処理は廃止しました。当面は正式なベースURLにcanonicalを統一し、言語クエリを別ページとして増殖させません。[Googleの言語別ページの要件](https://developers.google.com/search/docs/specialty/international/localized-versions)、[JavaScript SEOの注意点](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)。

海外流入をさらに増やす次段階は、承認後に英語の静的ゲーム紹介ページを追加する方法を推奨します。例：/en/games/ と /en/games/ai-or-not/。利点は英語HTML・SNSカード・相互hreflangを確実に出せること。欠点は翻訳とページ生成の保守が増えることです。既存URLは残し、ゲーム自体は同じURLにリンクできるのでセーブデータ移行は不要です。別案として同じ ?lang=en にCloudflare側で英語HTMLを返す方法がありますが、静的構成から配信処理が増えるため今回は導入していません。どちらも無断移行はしていません。

1. Search Consoleで「ドメイン」プロパティ nikuneko.com を追加（既存ならそのプロパティを使用）。
2. 表示された所有権確認用TXTレコードをCloudflare DNSに追加し、確認。確認トークンを勝手に生成したり、他の所有者の値を削除したりしないでください。[Google所有権確認手順](https://support.google.com/webmasters/answer/9008080)。

5. 数日〜数週間後にインデックス登録状況、検索パフォーマンスの国・クエリ、重複/canonical、Core Web Vitalsを確認。登録・順位改善は保証されません。
